Privacy Policy

Sky Gap Escape

Effective Date: 6 June 2026

Overview

Sky Gap Escape is a standalone game developed by Bisan Subba. This Privacy Policy explains how the game handles user information.

Data Collection

Sky Gap Escape does not collect, store, share, or transmit any personal information from users.

No Account Required

The game does not require users to create an account, sign in, or provide personal details.

No Advertising or Tracking

Sky Gap Escape does not include third-party advertising, analytics tracking, or user profiling.

Offline Gameplay

The game is designed to run as a standalone desktop game. It does not require an internet connection for gameplay.

Children's Privacy

Since Sky Gap Escape does not collect personal information, no personal data is knowingly collected from children.

Changes to This Policy

This Privacy Policy may be updated if the game changes in the future. Any updates will be posted on this page.

Contact

For questions about this Privacy Policy, please contact the developer through the official store listing or developer profile.
